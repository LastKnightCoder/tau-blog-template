# Tau Blog

Publish the articles, cards, and project docs you write in Tau as a clean personal blog. Readers can browse comfortably on desktop or mobile and search across your entire site.

## Get Started in 3 Steps

1. **Install the template**: Search for and install **Tau Blog** in the Plugin Center.
2. **Choose the template**: Open **Publish › Site Settings › Blog Template** in the Sidebar and select **Tau Blog**. Fill in **Site description** if you want an intro shown on the home page.
3. **Publish your content**: Select the articles, cards, or projects you want to share and publish your site.

## What It Includes

- **Articles**: Organize blog posts by tags and categories with clean reading typography.
- **Cards**: Present published knowledge cards in a dedicated section for easy browsing and linking.
- **Projects**: Display full project documentation trees. Project doc cards inside articles keep their editor styling, and clicking anywhere on a card opens that document.
- **Full-text search**: Search quickly across all published articles, cards, and projects.
- **Rich content display**: Supports syntax highlighting, math formulas, and image galleries. Galleries preserve their editor layout, and clicking any image zooms in.
- **Light/dark themes and responsive layout**: Switch between light and dark themes with layouts adapted for desktop, tablet, and mobile screens.

## FAQ

**How do I hide the intro section on the home page?** Leave **Site description** blank under **Publish › Site Settings › Blog Template**, and the intro section will not be shown.

**Will existing links break if I switch to another blog template later?** As long as you switch to a template that uses the same page paths (such as **Mochi Shop**), links you have already shared will keep working.

**How do I update my blog after editing documents?** Save your edits in Tau, then return to the **Publish** page and publish again to update your site.
