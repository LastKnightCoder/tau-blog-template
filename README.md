# 🚀 Tau 博客模板

一个现代化、优雅的个人博客模板。

## ✨ 在线演示

👉 [https://www.xiongtao.life](https://www.xiongtao.life)

## 🎯 功能

- 📝 **文章** - 博客文章展示和阅读
- 🎴 **卡片** - 知识卡片整理
- 🛠️ **项目** - 项目作品展示
- 🔍 **搜索** - 全文内容搜索

## 🌟 特性

- 📱 响应式设计，适配所有设备
- 🌙 浅色/深色主题切换
- 📖 Markdown、代码高亮、数学公式支持
- 🏷️ 标签和分类管理
- 📇 项目文档卡片保留编辑器样式，点击整张卡片跳转对应文档

## 📦 使用

1. 打开 Tau 应用
2. 进入插件中心
3. 搜索 `tau.blog` 并安装

安装后，你的内容会自动以博客形式展示。
