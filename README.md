# Tau 博客

把你在 Tau 里写的文章、卡片和项目文档直接发布成一个清爽的个人博客。读者在电脑和手机上都能顺畅阅读，也能快速检索整站内容。

## 三步开始

1. **安装模板**：在插件中心搜索并安装「Tau 博客」。
2. **选用模板**：打开侧边栏的「发布 › 站点设置 › 博客模板」，选择「Tau 博客」；如果希望首页展示简介，可以一并填写「站点描述」。
3. **发布内容**：勾选要公开的文章、卡片或项目，点击发布即可生成博客。

## 支持的内容与特性

- **文章**：按标签和分类组织博客文章，阅读页提供清晰的正文排版。
- **卡片**：独立展示公开的知识卡片，方便读者浏览和跳转关联内容。
- **项目**：完整呈现项目文档结构；文章里插入的项目文档卡片会保留编辑器中的样式，点击整张卡片即可跳转对应文档。
- **全文搜索**：支持在全站范围内快速搜索文章、卡片和项目内容。
- **正文呈现**：支持代码高亮、数学公式与图册展示；正文里的图册保留编辑器中的布局，点击图片可放大查看。
- **明暗主题与多端适配**：支持浅色与深色主题切换，自动适配电脑、平板和手机屏幕。

## 常见问题

**首页不想显示站点简介怎么办？** 在「发布 › 站点设置 › 博客模板」中将「站点描述」留空，首页就不会显示介绍区。

**以后换用别的博客模板，旧链接会失效吗？** 只要切换到使用相同页面路径的模板（如「团子铺」），已分享出去的链接依然可以正常访问。

**修改文章后怎么更新博客？** 在 Tau 里编辑并保存内容后，回到「发布」页重新发布即可更新站点。
