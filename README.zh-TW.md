# Tau 部落格

把你在 Tau 裡寫的文章、卡片和專案文件直接發佈成一個清爽的個人部落格。讀者在電腦和手機上都能順暢閱讀，也能快速搜尋整站內容。

## 三步開始

1. **安裝模板**：在外掛中心搜尋並安裝「Tau 部落格」。
2. **選用模板**：開啟側邊欄的「發佈 › 站點設定 › 部落格模板」，選擇「Tau 部落格」；如果希望首頁顯示簡介，可以一併填寫「站點描述」。
3. **發佈內容**：勾選要公開的文章、卡片或專案，點擊發佈即可產生部落格。

## 支援的內容與特色

- **文章**：依標籤與分類整理部落格文章，閱讀頁提供清晰的內文排版。
- **卡片**：獨立展示公開的知識卡片，方便讀者瀏覽與跳轉關聯內容。
- **專案**：完整呈現專案文件結構；文章裡插入的專案文件卡片會保留編輯器中的樣式，點擊整張卡片即可跳轉對應文件。
- **全文搜尋**：支援在全站範圍內快速搜尋文章、卡片與專案內容。
- **內文呈現**：支援程式碼醒目提示、數學公式與圖冊展示；內文裡的圖冊保留編輯器中的排版，點擊圖片可放大檢視。
- **明暗主題與多裝置適配**：支援淺色與深色主題切換，自動適配電腦、平板與手機螢幕。

## 常見問題

**首頁不想顯示站點簡介怎麼辦？** 在「發佈 › 站點設定 › 部落格模板」中將「站點描述」留空，首頁就不會顯示介紹區。

**以後換用別的部落格模板，舊連結會失效嗎？** 只要切換到使用相同頁面路徑的模板（例如「糰子舖」），已分享出去的連結依然可以正常開啟。

**修改文章後怎麼更新部落格？** 在 Tau 裡編輯並儲存內容後，回到「發佈」頁重新發佈即可更新站點。
